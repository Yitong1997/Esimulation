### 一、 初始定义与积分重构

假设在输入面 $(x_1, y_1)$，光场具有宏观曲率半径 $R_1$，我们将其强行拆分为残差复振幅 $u_1$ 和宏观球面波相位：


$$U_1(x_1, y_1) = u_1(x_1, y_1) \exp\left[ i\frac{\pi}{\lambda R_1} (x_1^2 + y_1^2) \right]$$

根据菲涅耳衍射积分，传播距离 $z$ 后的光场 $U_2(x_2, y_2)$ 为（为了简洁，省略常数系数和 $y$ 坐标，只推导 $x$ 维度）：


$$U_2(x_2) = \frac{1}{i\lambda z} \int U_1(x_1) \exp\left[ i\frac{\pi}{\lambda z} (x_2 - x_1)^2 \right] dx_1$$

将 $U_1$ 的表达式代入积分，并将指数项展开，我们得到积分内部的总相位（提取出公因子 $i\pi/\lambda$）：


$$\text{Phase} = \frac{x_1^2}{R_1} + \frac{1}{z}(x_1^2 - 2x_1x_2 + x_2^2)$$

### 三、 消除交叉项：坐标缩放的魔法（核心推导）

现在，我们要处理指数括号里的那一长串项。我们利用 $R_2 = R_1 + z$ 来化简两端的系数：

1. **$x_1^2$ 的系数：** $\frac{1}{R_1} + \frac{1}{z} = \frac{R_1+z}{R_1 z} = \frac{R_2}{R_1 z}$
2. **$x_2^2$ 的系数：** $\frac{1}{z} - \frac{1}{R_2} = \frac{R_2 - z}{z R_2} = \frac{R_1}{z R_2}$

将化简后的系数代回括号中，括号内的表达式变为：


$$\left[ \frac{R_2}{R_1 z} x_1^2 - \frac{2}{z} x_1 x_2 + \frac{R_1}{R_2 z} x_2^2 \right]$$

**这里是最关键的一步（PROPER的底层逻辑）：引入放大率 $m$。**
宏观光束截面在传播中会几何放大，放大率为 $m = \frac{R_2}{R_1}$。
我们在输出面引入**缩放坐标系** $x'_2$，使得 $x_2 = m x'_2 = \frac{R_2}{R_1} x'_2$。

将 $x_2$ 替换为缩放坐标：

* 中间交叉项变为： $-\frac{2}{z} x_1 \left( \frac{R_2}{R_1} x'_2 \right) = -\frac{2 R_2}{R_1 z} x_1 x'_2$
* 尾部平方项变为： $\frac{R_1}{R_2 z} \left( \frac{R_2}{R_1} x'_2 \right)^2 = \frac{R_1}{R_2 z} \frac{R_2^2}{R_1^2} (x'_2)^2 = \frac{R_2}{R_1 z} (x'_2)^2$

神奇的事情发生了！这三项现在拥有了一个完全相同的公因子 $\frac{R_2}{R_1 z}$，提取出来后：


$$\frac{R_2}{R_1 z} \left[ x_1^2 - 2x_1 x'_2 + (x'_2)^2 \right] = \frac{R_2}{R_1 z} (x_1 - x'_2)^2$$

### 一、 为什么我的推导会有 $\exp\left( i\frac{\pi}{\lambda f} x_2^2 \right)$？（几何物理意义）

### 二、 那么，什么时候焦平面上才是完美的“平面波”（无穷大曲率）？

你的直觉觉得应该是纯粹的 $\mathcal{F}\{u_1\}$（没有任何二次相位），这就引出了傅里叶光学中一个非常著名的结论：**要消除焦平面上的二次相位，物体不能贴在透镜上，而必须放在透镜的“前焦面”上。**

如果我们将输入场 $u_0(x_0)$ 放在透镜**前方**距离为 $f$ 的位置（前焦面），光波先在自由空间衍射距离 $f$，然后穿过透镜，再衍射距离 $f$ 到达后焦面。
经过极其繁琐的三步积分推导（自由空间 + 透镜相位 + 自由空间），奇迹会出现：透镜前方的传播正好抵消了后方的二次相位。最终后焦面上的光场为：

$$U_2(x_2) = \frac{1}{i\lambda f} \mathcal{F}\{u_0(x_0)\}$$

**在这里，二次相位彻底消失了！此时焦平面上的曲率确实是 $R = \infty$（纯平面波）。**

### 三、 关于高斯光束束腰的“冲突”

1. 只有当输入的高斯光束束腰正好位于透镜的**前焦面**时，经过透镜后，新的束腰才会精确地落在透镜的**后焦面**（$z=f$）上。此时，由于处于束腰位置，相位确实是纯平的（$R=\infty$），这完美符合了第二节中“物体放在前焦面，后焦面无二次相位”的傅里叶光学结论。
2. 如果在 PROPER 或任何传播软件中，你定义的高斯束腰在透镜表面，或者光束以其他状态经过透镜，那么在物理距离 $z=f$ 这个几何焦平面上，高斯光束**并没有到达（或者已经越过了）它的真实束腰**。既然不在真实束腰处，它的波前当然是弯曲的！而积分方程诚实地告诉你，此时的等效曲率半径恰好是 $R=f$。

### 三、 二次相位的坍缩（FFT的诞生）

这正是一个纯粹的傅里叶变换。在 PROPER 中，计算机会执行以下操作：

1. 计算出新的残差复振幅： $u_2(x_2) = \mathcal{F} \{ u_1(x_1) \}$
2. 将新的参考球面曲率更新为： $R_2 = d$ （发散波）

$$U_2(x_2) = u_2(x_2) \exp\left( i\frac{\pi}{\lambda d} x_2^2 \right)$$

$$\text{Phase of } u_2(x_2) = \exp\left( -i\frac{\pi}{\lambda d} x_2^2 \right)$$

$$U_2(x_2) = \underbrace{ \left| u_2(x_2) \right| \exp\left( -i\frac{\pi}{\lambda d} x_2^2 \right) }_{\text{FFT 算出的 } u_2(x_2)} \cdot \underbrace{ \exp\left( i\frac{\pi}{\lambda d} x_2^2 \right) }_{\text{积分提取的参考相位}}$$

$$U_2(x_2) = \left| u_2(x_2) \right|$$

没有虚部，没有二次相位。**它在物理上，完完全全坍缩成了一个波前绝对平坦的束腰平面波。**

### 第一步：写出源平面 $z = -d$ 的真实光场与残差场 $u_1(x_1)$

假设一个高斯光束，其束腰位于 $z=0$ 处，束腰半径为 $w_0$。
根据高斯光束传播理论，在距离束腰为 $d$ 的源平面（$z = -d$）处，光束的物理参数如下：

* **瑞利长度：** $z_R = \frac{\pi w_0^2}{\lambda}$
* **光斑半径：** $w_1^2 = w_0^2 \left[ 1 + \left(\frac{d}{z_R}\right)^2 \right] = \frac{\lambda z_R}{\pi} \frac{d^2 + z_R^2}{z_R^2}$
* **物理波前曲率：** $R_{gauss} = -d \left[ 1 + \left(\frac{z_R}{d}\right)^2 \right] = -\frac{d^2 + z_R^2}{d}$ （负号表示汇聚）

因此，源平面的**真实物理光场**为：


$$U_1(x_1) = \exp\left( -\frac{x_1^2}{w_1^2} \right) \exp\left( i\frac{\pi}{\lambda R_{gauss}} x_1^2 \right)$$

在 PROPER 中，我们指派了一个几何参考球面波。由于几何焦点在 $z=0$，参考曲率为 $R_{ref} = -d$。所以**参考波前相位**为：


$$U_{ref}(x_1) = \exp\left( i\frac{\pi}{\lambda (-d)} x_1^2 \right) = \exp\left( -i\frac{\pi}{\lambda d} x_1^2 \right)$$

PROPER 要进行 FFT 的对象是**残差复振幅 $u_1(x_1)$**，它是真实光场除以参考波前：


$$u_1(x_1) = \frac{U_1(x_1)}{U_{ref}(x_1)} = \exp\left( -\frac{x_1^2}{w_1^2} \right) \exp\left[ i\frac{\pi}{\lambda} \left( \frac{1}{R_{gauss}} + \frac{1}{d} \right) x_1^2 \right]$$

### 第二步：化简残差场的复数指数

为了做 FFT，我们需要把 $u_1(x_1)$ 写成标准高斯形式 $\exp(-\alpha x_1^2)$。
先来计算指数上的那个微小的“相位补偿项”（即曲率差）：


$$\Delta K = \frac{1}{R_{gauss}} + \frac{1}{d} = -\frac{d}{d^2 + z_R^2} + \frac{1}{d} = \frac{-d^2 + d^2 + z_R^2}{d(d^2 + z_R^2)} = \frac{z_R^2}{d(d^2 + z_R^2)}$$

再把 $\frac{1}{w_1^2}$ 用 $z_R$ 展开：


$$\frac{1}{w_1^2} = \frac{\pi}{\lambda z_R} \frac{z_R^2}{d^2 + z_R^2} = \frac{\pi z_R}{\lambda(d^2 + z_R^2)}$$

将它们合并，残差场 $u_1(x_1) = \exp(-\alpha x_1^2)$ 中的复数系数 $\alpha$ 为：


$$\alpha = \frac{1}{w_1^2} - i\frac{\pi}{\lambda}\Delta K = \frac{\pi z_R}{\lambda(d^2 + z_R^2)} - i\frac{\pi z_R^2}{\lambda d(d^2 + z_R^2)}$$

提取公因子，我们得到极其优雅的形式：


$$\alpha = \frac{\pi z_R}{\lambda(d^2 + z_R^2)} \left( 1 - i\frac{z_R}{d} \right)$$


*(你看，这就我上一版提到的带有特定“啁啾”系数的输入端！)*

### 第三步：执行严谨的解析傅里叶积分

现在，我们对 $u_1(x_1)$ 进行傅里叶变换。空间频率为 $f_x = \frac{x_2}{\lambda d}$。
根据标准的傅里叶积分公式 $\mathcal{F}\{e^{-\alpha x^2}\} \propto \exp\left(-\frac{\pi^2 f_x^2}{\alpha}\right)$，输出场 $u_2(x_2)$ 的指数部分（我们只关心指数）为：


$$\text{Exponent} = -\frac{\pi^2}{\alpha} \left( \frac{x_2}{\lambda d} \right)^2 = -\frac{\pi^2 x_2^2}{\lambda^2 d^2 \alpha}$$

将上面求得的 $\alpha$ 代入分母：

$$U_1(x_1) = u_1(x_1) \exp\left( i\frac{\pi}{\lambda R_1} x_1^2 \right)$$

*注意：此时 $u_1(x_1)$ 已经通过除法吸纳了所有的像差 $\delta t$ 和高斯轮廓偏离，它是纯粹要在计算机内存（RAM）中进行数值计算的二维矩阵。*

---

### 第二阶段：代入菲涅耳绝对积分

将物理总场代入标准的菲涅耳（Fresnel）衍射积分：


$$U_2(x_2) = \frac{e^{ikz}}{i\lambda z} \int \left[ u_1(x_1) \exp\left( i\frac{\pi}{\lambda R_1} x_1^2 \right) \right] \exp\left[ i\frac{\pi}{\lambda z} (x_2 - x_1)^2 \right] dx_1$$

展开积分核中的平方项，合并所有包含 $x_1$ 和 $x_2$ 的指数项：


$$U_2(x_2) = \frac{e^{ikz}}{i\lambda z} \int u_1(x_1) \exp\left\{ i\frac{\pi}{\lambda} \left[ x_1^2\left(\frac{1}{R_1} + \frac{1}{z}\right) - \frac{2 x_1 x_2}{z} + \frac{x_2^2}{z} \right] \right\} dx_1$$

这就是所有计算的绝对母方程。接下来，**PROPER 算法的伟大分水岭出现了**。根据几何光束是否到达焦点，算法必须在数学上分裂为两条独立的分支（这也是为什么 PROPER 源码里有 `prop_ptp` 和 `prop_ptf` 两个不同函数的原因）。

---

### 第三阶段（分支A）：向非焦点平面传播（近场/中场缩放）

如果不经过焦点，几何参考球面波的演化服从简单的自由空间增长：


$$R_2 = R_1 + z \quad (\text{且 } R_2 \neq 0)$$

我们要在平面2上强制重构出 PROPER 的标准形式，即 $U_2(x_2) = u_2(x_2) \exp\left( i\frac{\pi}{\lambda R_2} x_2^2 \right)$。
将 $\exp\left( i\frac{\pi}{\lambda R_2} x_2^2 \right)$ 从母方程的积分号外强行提出，积分号内部必须减去这个相位：


$$u_2(x_2) = \frac{e^{ikz}}{i\lambda z} \int u_1(x_1) \exp\left\{ i\frac{\pi}{\lambda} \left[ x_1^2\left(\frac{1}{R_1} + \frac{1}{z}\right) - \frac{2 x_1 x_2}{z} + x_2^2\left(\frac{1}{z} - \frac{1}{R_2}\right) \right] \right\} dx_1$$

**严密的坐标缩放代换：**
代入 $R_2 = R_1 + z$，计算各项系数：

* $x_1^2$ 系数： $\frac{1}{R_1} + \frac{1}{z} = \frac{R_2}{R_1 z}$
* $x_2^2$ 系数： $\frac{1}{z} - \frac{1}{R_2} = \frac{R_1}{R_2 z}$

引入缩放系数 $m = \frac{R_2}{R_1}$，令网格坐标发生缩放 $x_2 = m \cdot x'_2 = \frac{R_2}{R_1} x'_2$。代入上式化简（过程极度舒适）：

* 交叉项变为： $-\frac{2}{z} x_1 \left(\frac{R_2}{R_1} x'_2\right) = -\frac{2 R_2}{R_1 z} x_1 x'_2$
* 平方项变为： $\frac{R_1}{R_2 z} \left(\frac{R_2}{R_1} x'_2\right)^2 = \frac{R_2}{R_1 z} (x'_2)^2$

三项提取公因子 $\frac{R_2}{R_1 z} = \frac{m}{z}$，并在外层定义等效传播距离 $z_{eff} = \frac{z}{m}$。
原积分完美坍缩为标准的无缩放菲涅耳卷积：


$$u_2(m x'_2) = \frac{e^{ikz}}{i\lambda z} \int u_1(x_1) \exp\left[ i\frac{\pi}{\lambda z_{eff}} (x_1 - x'_2)^2 \right] dx_1$$

**算法实现（分支A）：** 计算机对 $u_1$ 进行一次等效距离为 $z_{eff}$ 的角谱传播（两次FFT），然后物理网格间距乘以 $m$。庞大的宏观二次相位被纯解析的 $m$ 和 $z_{eff}$ 完美接管。

---

### 第四阶段（分支B）：向焦点平面传播（算法降维打击）

这是你最关心的束腰/焦平面。
如果传播目标正是几何焦点，意味着传播距离 $z = -R_1$。
此时，$R_2 = R_1 + z = 0$。

如果在分支 A 中继续推导，放大率 $m = R_2/R_1 = 0$ 将导致网格崩溃（物理意义是光束试图缩成一个无穷小的点）。
因此，我们必须退回“第二阶段”的母方程，代入 $z = -R_1$：

母方程中的 $x_1^2$ 系数为： $\frac{1}{R_1} + \frac{1}{z} = \frac{1}{R_1} - \frac{1}{R_1} = 0$
**最核心的物理发生：源面的宏观曲率与衍射核的发散曲率在此刻绝对归零。**

母方程坍缩为：


$$U_2(x_2) = \frac{e^{ikz}}{i\lambda z} \exp\left( i\frac{\pi}{\lambda z} x_2^2 \right) \int u_1(x_1) \exp\left( -i\frac{2\pi}{\lambda z} x_1 x_2 \right) dx_1$$

**PROPER 的重置定律（Pilot Beam Reset）：**
到达焦点后，旧的参考球面波已经死亡。PROPER 利用积分式自动外溢的 $\exp\left( i\frac{\pi}{\lambda z} x_2^2 \right)$ 作为**新生**的参考球面波。由于这个波是从距离 $z$ 外的透镜/源平面发散过来的，所以新的曲率半径 $R_{new} = z$。

于是，系统剥离出残差项：


$$u_2(x_2) = \frac{e^{ikz}}{i\lambda z} \int u_1(x_1) \exp\left( -i\frac{2\pi}{\lambda z} x_1 x_2 \right) dx_1$$

**算法实现（分支B）：**
这已经是一个纯粹的单步离散傅里叶变换（FFT）。
计算机只需执行： $u_2 = \text{FFT}(u_1)$。
系统将当前平面的宏观曲率半径记录为 $R_2 = z$。

### 终章：算法与物理现实的巅峰对接

当计算机做完这步纯 FFT 后，算出来的 $u_2$ 到底是什么？这正是我们前面的加法/乘法推导大显身手的地方。

回忆我们在第一阶段定义的 $u_1(x_1)$，它包含了理想残差 $u_{ideal}$ 和任意乘法像差 $t(x_1)$。
根据傅里叶卷积定理：


$$u_2(x_2) = \text{FFT}\{ u_1(x_1) \} = \tilde{u}_{ideal}(x_2) \ast T(x_2)$$

* $\tilde{u}_{ideal}(x_2)$ 是那个自带反向补偿相位的完美高斯傅里叶解。
* $T(x_2)$ 是像差的频谱分布。

真实光场的最终重构：


$$U_{2,real}(x_2) = u_2(x_2) \exp\left( i\frac{\pi}{\lambda z} x_2^2 \right) = \left[ \tilde{u}_{ideal}(x_2) \ast T(x_2) \right] \exp\left( i\frac{\pi}{\lambda z} x_2^2 \right)$$

**全剧终：**

1. **宏观被剥离：** 极其庞大且会导致奈奎斯特混叠的球面相位 $\exp( i\frac{\pi}{\lambda z} x_2^2 )$，被 PROPER 用纯数学变量 $R_{new}=z$ 安全地收容了。
2. **微观交由 FFT：** 所有的物理畸变、衍射环、焦移、像差，全都在那个没有采样压力的 $u_2(x_2)$（即卷积 $\tilde{u}_{ideal} \ast T$）中被精准计算了出来。
3. **完美闭环：** 如果没有像差（$T=\delta$），卷积化简，自带的反向相位与外部的 $\exp( i\frac{\pi}{\lambda z} x_2^2 )$ 精确相消，系统自动在物理上还原出曲率为无穷大的平坦束腰；如果有像差，卷积后的相位无法抵消，系统忠实地描绘出焦点处崎岖的波前畸变。

这套体系没有任何近似，也没有任何物理矛盾。数学公式用最冷酷的推导，接管并证明了所有的物理直觉。

### 一、 算法触发单步 FFT 的唯一数学铁律

任何带有解析追踪的传播算法（如 PROPER），触发单步 FFT 的条件只有一个，且完全是数学上的：
**当且仅当传播距离 $z$ 等于当前参考球面波（Pilot Beam）曲率半径的绝对值，且参考波为汇聚波时（即 $z = -R_{ref}$ ）。**

此时，参考球面波在目标平面上缩成了一个几何点，宏观曲率 $R_2 = R_{ref} + z = 0$。为了避免缩放因子 $m = 0$ 导致的网格崩溃，积分方程中的二次交叉项完美抵消，算法自动降维成单步 FFT 。

### 二、 非理想像差条件下的绝对严密推导

现在，我们设定一个最真实、最复杂的物理场景：
一束带有任意振幅调制和相位像差的光，穿过了一个焦距为 $f$ 的透镜。透镜表面为源平面（平面1）。

**1. 物理真实光场的定义**
假设穿过透镜后的真实物理总场为 $U_{real}(x_1)$。它包含高斯基底、透镜造成的汇聚、以及极其复杂的像差调制函数 $t(x_1) = A(x_1)\exp[i\Phi(x_1)]$：


$$U_{real}(x_1) = U_{ideal\_gauss}(x_1) \cdot \exp\left(-i\frac{\pi}{\lambda f} x_1^2\right) \cdot t(x_1)$$

**2. 算法第一步：剥离纯几何参考波**
在 PROPER 的逻辑中，既然光穿过了一个焦距为 $f$ 的透镜，系统就会死板地、严密地指派一个几何参考球面波 ：


$$U_{ref}(x_1) = \exp\left(-i\frac{\pi}{\lambda f} x_1^2\right)$$


注意，这个 $U_{ref}$ 里没有任何像差，也没有高斯光束的物理参数，它是纯几何的。

计算机提取要进行数值计算的残差矩阵 $u_1(x_1)$：


$$u_1(x_1) = \frac{U_{real}(x_1)}{U_{ref}(x_1)} = U_{ideal\_gauss}(x_1) \cdot t(x_1)$$


此时，所有的像差、物理高斯分布的畸变，全部被打包塞进了这个 $u_1(x_1)$ 中。

**3. 向前传播的积分母方程**
我们将场向前传播任意距离 $z$。代入标准的 Fresnel 积分，提出参考相位：


$$U_2(x_2) = \dots \int u_1(x_1) \exp\left\{ i\frac{\pi}{\lambda} \left[ x_1^2\left(-\frac{1}{f} + \frac{1}{z}\right) - \frac{2 x_1 x_2}{z} + \frac{x_2^2}{z} \right] \right\} dx_1$$

### 三、 为什么单步 FFT 只适用于几何焦平面？

现在，我们来审视两个不同的目标平面：

#### 场景 A：目标是几何焦平面（ $z = f$ ）

将 $z = f$ 代入母方程，积分号内部 $x_1^2$ 的系数必定为 $( -1/f + 1/f ) = 0$ 。
极其庞大的二次振荡项在数学上被完美抹平。方程干净利落地坍缩为：


$$U_2(x_2) = \exp\left( i\frac{\pi}{\lambda f} x_2^2 \right) \int u_1(x_1) \exp\left( -i\frac{2\pi}{\lambda f} x_1 x_2 \right) dx_1$$

这正是一个**单步 FFT**： $u_2(x_2) = \mathcal{F} \{ u_1(x_1) \}$ 。
**结论：无论 $u_1(x_1)$ 里面包含多么离谱的非理想像差，只要你传播的距离 $z$ 刚好等于几何焦距 $f$，积分核自身的二次项必定完全抵消。单步 FFT 在此平面绝对成立。**

#### 场景 B：目标是真实的物理束腰（ $z = z_{waist} \neq f$ ）

正如前文所述，由于焦移现象，真实的高斯光束（尤其是带有像差的高斯光束），其物理束腰位置 $z_{waist}$ 几乎不可能刚好等于 $f$ 。
当我们强行要求算法传播到束腰面时，代入 $z = z_{waist}$，母方程中的 $x_1^2$ 系数变为：


$$-\frac{1}{f} + \frac{1}{z_{waist}} \neq 0$$


**致命的数学结果出现了：** $x_1^2$ 前面的二次相位无法抵消！
方程内部依然残留着 $\exp( i\frac{\pi}{\lambda \Delta z} x_1^2 )$ 这样的啁啾项。既然有二次项，这就绝对不可能化简为一个纯粹的单步傅里叶变换。
此时，算法必须走“等效卷积”的分支 。它会定义新的曲率 $R_2 = -f + z_{waist}$，引入缩放因子 $m$，然后执行两次 FFT（角谱法/等效卷积）来算出束腰面的场 。

### 四、 终极结论总结

1. 
**单步 FFT 对应的是什么？** 它对应的是**参考球面波（Pilot Beam）曲率收敛到 0 的那个纯几何平面**。对于透镜系统，这必定是几何焦平面 。


2. 
**为什么不管束腰？** 算法（如 PROPER）是由几何光学定律驱动参考波的 。透镜焦距是 $f$，参考波就汇聚到 $f$。算法并不知道也不关心你输入的到底是个高斯光束、平顶光束、还是带严重像差的散斑场。物理束腰是在这些复杂场演化中产生的结果，而不是驱动算法网格的原因。


3. 
**在焦平面算单步 FFT，算出来的物理意义是什么？** 算出来的正是**非理想光学系统的点扩散函数（PSF）或焦斑**。通过 FFT 计算 $u_1(x_1)$（包含所有像差 $t(x_1)$），焦平面上的光场会忠实地展现出彗星尾巴、像散十字、或是被畸变破坏的非对称光斑 。



**总结一句话：** 单步 FFT 是数学解析几何与离散网格妥协的产物，它被死死钉在了几何焦平面上；而真实的束腰，是带有像差的物理光场自己在空间中“扭曲”出来的，算法如果要去追束腰，就只能老老实实用带缩放的卷积（两次 FFT）一步步算过去。
